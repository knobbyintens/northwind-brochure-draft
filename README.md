# Northwind Brochure Template

Minimal Jekyll brochure site used for studio capability pages.

## How to use

1. Copy this template into a new repository.
2. Replace the placeholder copy in `index.md` and `_pages/`.
3. Update every value in `_config.yml` before publishing. This template ships with
   placeholder values only.
4. Remove any page that the publishing standard says we must not publish.

This repository is deployed as a GitHub Pages *project site* (a repository under
our account, not the account's root pages site), so the generated paths are
sensitive to the final repository name.
